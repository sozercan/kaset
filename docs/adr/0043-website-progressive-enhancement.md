# ADR-0043: Accessible and Resilient Website

## Status

Accepted

## Decision

Keep a live status region for the website's copy buttons. Their accessible names tell screen reader users what will be copied, but those names hide the temporary visual “Copied” text from assistive technology. The status region announces a successful copy without changing the accessible name or moving focus.

Keep the GitHub releases link in the page markup. The release lookup enhances it with a version and a direct DMG URL when available. If JavaScript is unavailable, the lookup fails, or the release has no DMG asset, the original link still takes users to the release page.

Keep white button labels at a contrast ratio of at least 4.5:1 against either side's primary accent. On narrow screens, clip the decorative glow horizontally without clipping the vertical layout, switch four-column tiles to two before the AppleScript example becomes too narrow, and let long commands wrap instead of clipping them.

Both cassette faces use the same reel geometry: the more heavily wound left spool shows a tape mid-play, and the tape path runs along the lower tangent of both spools. Update the path together with the reel radii if the illustration changes.
